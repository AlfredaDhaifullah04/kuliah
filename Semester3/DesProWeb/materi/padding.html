Apa itu Padding?

Padding adalah ruang antara konten elemen dan border-nya. Padding membuat elemen terlihat lebih lapang dan mudah dibaca.

Properti Padding

Padding dapat diatur untuk setiap sisi elemen secara individual:

padding-top: Mengatur padding atas

padding-right: Mengatur padding kanan

padding-bottom: Mengatur padding bawah

padding-left: Mengatur padding kiri

padding: Shorthand untuk mengatur semua padding

Shorthand Padding

Properti padding dapat menerima 1 hingga 4 nilai:

padding: 20px; → semua sisi 20px

padding: 20px 40px; → atas-bawah: 20px, kiri-kanan: 40px

padding: 10px 20px 30px; → atas: 10px, kiri-kanan: 20px, bawah: 30px

padding: 10px 20px 30px 40px; → atas: 10px, kanan: 20px, bawah: 30px, kiri: 40px

Padding vs Margin

Padding

Ruang di dalam elemen, antara konten dan border

Kelebihan:

  • Meningkatkan keterbacaan
  • Memisahkan konten dari border
  • Latar belakang padding terpengaruh warna latar elemen

Margin

Ruang di luar elemen, antara border dan elemen lain

Kelebihan:

  • Mengontrol jarak antar elemen
  • Tidak terpengaruh warna latar elemen
  • Berguna untuk membuat tata letak

Kesalahan Umum

  • Terlalu banyak padding dapat membuat elemen terlalu besar
  • Lupa bahwa padding menambah lebar dan tinggi total elemen
  • Penggunaan padding yang tidak konsisten antar elemen

Tips Praktis

  • Gunakan satuan relatif (em, rem) untuk padding yang responsive
  • Gunakan box-sizing: border-box agar padding tidak menambah lebar elemen
  • Buat konsistensi dengan mendefinisikan padding dalam sistem desain
