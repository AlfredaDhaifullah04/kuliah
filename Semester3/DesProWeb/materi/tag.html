Berapa Banyak Tag HTML?

HTML terdiri dari berbagai tag yang digunakan untuk membuat struktur halaman web. Jumlah tag HTML telah berkembang seiring dengan perkembangan versi HTML.

142

HTML5, versi terbaru HTML, memiliki sekitar 142 tag yang terdefinisi. Namun, perlu dicatat bahwa tidak semua tag digunakan secara regular dalam pengembangan web sehari-hari.

Fakta Menarik

Dari 142 tag HTML yang tersedia, sebagian besar developer hanya menggunakan sekitar 30-40 tag secara regular dalam project sehari-hari.

Perhatian

Beberapa tag HTML sudah tidak digunakan lagi (deprecated) dan tidak disarankan untuk digunakan dalam pengembangan modern. Contohnya adalah tag <font>, <center>, dan <frame>.

Perkembangan Jumlah Tag HTML

Jumlah tag HTML telah berkembang signifikan sejak versi pertama:

  • HTML 2.0 (1995): Sekitar 40 tag
  • HTML 3.2 (1997): Sekitar 70 tag
  • HTML 4.01 (1999): Sekitar 120 tag
  • XHTML 1.0 (2000): Sekitar 120 tag
  • HTML5 (2014): Sekitar 142 tag

HTML5

HTML5 memperkenalkan banyak tag semantik baru seperti <header>, <footer>, <article>, <section>, dan <nav> yang membuat struktur halaman web lebih bermakna.
